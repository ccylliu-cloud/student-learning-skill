# 学习记录册 Skill · 1.0

把试卷和作业整理为可以长期积累、复核和复练的学生学习档案。支持 **Codex** 和 **WorkBuddy**，提供本地中文管理页面、错题本与Word导出。

已经下载ZIP的用户：解压后把整个文件夹交给Agent，发送“请读取此文件夹的README.md和student-learning/references/trial-installation.md，帮我安装并打开学习记录册”。

详细步骤见 **[安装指南](INSTALL.md)**。需要Python 3.10或以上；本版主要验收环境为macOS/Python 3.12。Windows安装路径已适配，实机仍欢迎反馈。

## 能做什么

- 从试卷、作业中定位批改错题候选，对照原图复核；遗漏题目可以圈选补充。
- 分开记录学生初答和订正，保留逐步证据及第一处可见变化，错因可保持待核。
- 关联随包提供的数学、英语、语文知识库，记录关联依据与缺口。
- 保存历史原件、错题、人工判定、复练记录；生成干净题面、组卷和Word错题本。
- 在本地中文页面管理档案，支持备份与恢复。学生资料不随安装包分发。

## Codex与WorkBuddy怎样使用

| 宿主 | 识别操作 |
|---|---|
| Codex | 本地页面可通过已登录的Codex CLI请求识别；也可在当前对话按Skill流程处理。后台默认请求gpt-6-astra/medium，可按本安装配置调整；模型不可用时应明确说明。 |
| WorkBuddy | 页面先保存请求，再回当前对话说“处理待识别试卷”；Agent完成看图、查库和提交后，回页面复核。补题与报告也使用这套对话接力。 |

两者共享保存校验与本地页面，实际看图效果仍受宿主模型、原图清晰度和上下文影响。当前不承诺所有Agent或模型效果一致；其他Agent尚未完成适配验收。

## 知识库与复核

| 学科 | 随包版本 | 数量 | 边界 |
|---|---|---:|---|
| 数学 | 0.6.0-body-review | 1211 | 内部审校版 |
| 英语 | 1.2.0 | 355 | 语法知识库，非逐题验算的评分答案库 |
| 语文 | 1.0.0 | 84 | 两级分类与能力定位 |

识别结果、模型题框、错因和知识关联均需复核；看不清或条件不全应保持待核。图题未核对干净题面前不能用于打印练习。物理等其他学科本版未接入。

## 试用与反馈

建议先用[合成试卷](TESTING.md)熟悉流程，再按宿主设置决定是否提交真实材料。模型处理由用户选择的宿主提供；“档案存本地”不代表识别时图像不会发给宿主模型。

遇到问题请看[常见问题与反馈](FEEDBACK.md)，或在[Issues](https://github.com/ccylliu-cloud/student-learning-skill/issues)留言。**不要公开上传学生姓名、真实试卷、数据库、账号密钥或完整对话日志。**

本版已通过44项隔离回归、两宿主程序安装检查、页面检查与2题合成中文试卷的实际Codex CLI识别；真实WorkBuddy/Windows、真实手写试卷大样本效果仍需继续试用。完整范围见[验收记录](ACCEPTANCE.md)。
